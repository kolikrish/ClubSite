# Club Site

Welcome to the **Abhyudaya Coding Club Site**! This is the official website of our club.

## Technologies Used

- **Frontend**: React (with React Router), Tailwind CSS
- **Backend**: Node.js, Express

## Getting Started

### Prerequisites

- Node.js and npm installed
- (Optional) Docker for containerized deployment

### Local Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/your-username/club-site.git
    cd club-site
    ```

2. Install dependencies:

    ```bash
    npm install
    ```

3. Start the development server:

    ```bash
    npm run dev
    ```

4. Access the site at [http://localhost:5173](http://localhost:5173).

### Build for Production

```bash
npm run build
```
